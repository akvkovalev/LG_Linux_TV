# Credits and upstream inputs

- LG Electronics publishes the model-specific Linux kernel sources and webOS
  toolchain used as external build inputs. They are not redistributed here.
- Alpine Linux supplies the ARMv7 minirootfs and package repositories.
- `kexec-tools` supplies the userspace loader.
- [lg-webos-kexec](https://github.com/ggfuchsi-oss/lg-webos-kexec) documented and
  demonstrated the RAM-only kexec approach on another Realtek LG television.
- Linux, BusyBox, musl, Xorg, xf86-video-fbdev, Openbox and OpenSSH retain their
  respective upstream licenses.

The hardware-specific fixes in this repository were verified on a physical
LG 43UN71006LB by the repository owner during October 2026.
